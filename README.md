# Social Card — HTML & CSS

**Simple, responsive social card** template built with pure HTML and CSS.  
Use this card to show your name, role, short bio and links to social profiles (WhatsApp, Instagram, LinkedIn, Telegram, Website). Perfect for GitHub profile README, personal sites, or as a component in projects.

---

## 🔥 Features
- Pure HTML + CSS (no JS required)
- Responsive and mobile-friendly
- Easy to customize (colors, icons, links, fonts)
- SVG icons included (Instagram, Telegram, WhatsApp, LinkedIn, Website)
- Ready to embed in GitHub Pages or any website

---

## 📁 Files
- `index.html` — demo social card
- `styles.css` — styling for the card
- (Optional) `assets/` — put images or logos here

---

## 🚀 Live demo
Open `index.html` in browser or host on GitHub Pages.
